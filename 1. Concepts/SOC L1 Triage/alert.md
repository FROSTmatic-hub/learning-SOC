# What are Alerts?
- An alert is generated when a [Security Solutions](/1.%20Concepts/SOC%20L1%20Triage/security_solutions.md) notices suspicious [Events](/1.%20Concepts/SOC%20L1%20Triage/events.md) or chain of [Events](/1.%20Concepts/SOC%20L1%20Triage/events.md) from the [Logs](/1.%20Concepts/SOC%20L1%20Triage/logs.md)
# Example
- **Normal Event:**
	1. User logs in
	2. User opens the browser
	3. User downloads PDF file

- **Alert Event:**
	1. User receives an email
	2. User clicks on the link
	3. PowerShell starts
	4. A file is downloaded
