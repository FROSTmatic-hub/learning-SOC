- The [Alert Assignee](/1.%20Concepts/SOC%20L1%20Triage/alert_assignee.md) has to write a detailed document report about the alert, [Alert Name](/1.%20Concepts/SOC%20L1%20Triage/alert_name.md), [Alert Verdict](/1.%20Concepts/SOC%20L1%20Triage/alert_verdict.md), etc.

