# What is a Misconfiguration?
- Misconfiguration is a security flaw that happens when someone mistakenly sets up the wrong permissions or configurations.
- They are not a bug or [Vulnerabilities](/1.%20Concepts/Attack%20on%20System/vulnerability.md) in the system or software itself. 

# Common Examples
- When a user uses weak passwords such as `111` or `12345`, etc.
- When a user mistakenly makes sensitive cloud data accessible to the public.
- When sensitive permissions or configurations are left enabled.
- When a new system is set up insecurely.
