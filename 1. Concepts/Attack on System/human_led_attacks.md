# What is Human-led Attacks?
- Sometimes, a human or user can be the starting point of an attack.
- For example, a user might:
	- Find and plug in a malicious USB drive
	- Download malicious applications from pirated/illegal websites.
	- Reuse the same weak password across multiple platforms

> [!NOTE] 
> Sometimes, the attacker does not need to break into a system. The user can open the door for the attacker to exploit.
