# What is an EDR Agent?
- An EDR agent is a software that is directly installed on an [Endpoint](/1.%20Concepts/Introduction%20to%20EDR/endpoint.md) device.
- It continuously monitors an [Endpoint](/1.%20Concepts/Introduction%20to%20EDR/endpoint.md) device for suspicious activites/logs such as:
	- Process changes
	- File changes
	- System activities
	- Network activities
	- etc
- EDR Agent sends all this data to [EDR Console](/1.%20Concepts/Introduction%20to%20EDR/EDR_console.md), often in real-time.

> [!NOTE] 
> EDR Agents are not just dumb data collectors. They can perform basic behavior-based, signature-based detections on an [Endpoint](/1.%20Concepts/Introduction%20to%20EDR/endpoint.md)
