# What is the EDR Console?
- An EDR console is the central point where all the data from the [EDR Agent](/1.%20Concepts/Introduction%20to%20EDR/EDR_agent.md) come together.
- The EDR console:
	- Collects data from agents.
	- Correlates information from different events/endpoints.
	- Analyzes the data using detection logic and machine learning.
	- Compares activity against threat intelligence.
	- Identifies suspicious patterns.
	- Generates detections/alerts.
