- Visibility is a feature of EDR that allows the [SOC](/1.%20Concepts/Blue%20Team%20Introduction/SOC.md) analyst to view (in detail) on what activites are happening on an [Endpoint](/1.%20Concepts/Introduction%20to%20EDR/endpoint.md) device.
- Activities such as:
	- Process changes
	- File changes
	- User accounts
	- etc.
# Process Tree
- Visibility displays the activites in process tree structure which makes it easy for the analyst to see what spawned what and what happened next
