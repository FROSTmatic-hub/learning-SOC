# Learning SOC 
Welcome to my personal cybersecurity notebook! I'm using this repository to document my journey toward becoming a Security Operations Center (SOC) Analyst. Instead of just memorizing definitions or CLI commands, my goal here is to connect the dots between core concepts, modern defensive tools, and real-world triage workflows.

### What I'm Aiming For

- **Build strong fundamentals:** Deepen my understanding of defensive security, networking, and threat landscapes.
- **Master SOC workflows:** Learn how alerts move from initial detection to triage, investigation, and incident response.
- **Document hands-on practice:** Write up lab reports, investigation walkthroughs, and key takeaways from practical exercises.
- **Maintain a growing reference:** Keep a structured, easily revisable knowledge base that evolves as I learn.

### What's Inside

| Section | Description |
| :--- | :--- |
| **Concepts** | Plain-English explanations of cybersecurity fundamentals, threat vectors, SOC operations, EDR platforms, alert triage, and key metrics. |
| **Labs** | Walkthroughs of practical exercises, real incident investigation reports, notes on errors, and lessons learned. |
---

### How I Approach Learning

I organize my notes around modular concepts and link related ideas together to map out how a security operation actually functions in practice. For instance, rather than looking at tools in isolation, I connect them like this:

> Endpoint → EDR → Alert Triage → SOC Analyst → Incident Investigation → Containment/Response

This graph-style approach helps me see the bigger picture behind defensive operations.
